# 구글시트 학생 데이터 연결

## 사용

- 편집 시트: https://docs.google.com/spreadsheets/d/1o363_FWYDARmI6vg8ZTRMf4SNF2WMKM-FhRJJV-5nfw/edit#gid=1874736550
- `Students` 탭은 합성 학생 총1,000건이며 전원 `active=TRUE`이다. `Guide` 탭에서 입력 규격을 확인한다.
- Students의 프로필·출석·상담 상태 또는 StudentCourses의 이수 상태(H)·평점(I)을 수정한 뒤 저장한다. Students 학점·GPA는 파생 수식이므로 직접 수정하지 않는다. 앱의 **지금 동기화**로 새로 읽거나 표시 중인 화면의60초 갱신을 기다린다. 비활성 탭은 주기 요청을 멈추고 다시 표시될 때 읽는다.
- 구글시트에서 앱으로 읽는 단방향 동기화다. 웹훅·즉시 push·앱에서 시트로의 쓰기는 구현하지 않았다. 실제 반영 시각은 시트 서비스 응답과 네트워크 지연에 따라 달라진다.
- 동기화 패널에서 출처, 표시 인원, 전체 시트 행 수, 최근 확인·마지막 반영 시각을 확인한다. 최초 실패 시 내장 합성 데모임을 표시하고, 성공 이후 실패 시 열린 화면의 마지막 정상 데이터를 보존한다. 브라우저를 새로 열면 이전 세션의 정상 데이터를 보관하지 않는다.
- 표시 인원·평균 이수율·조건별 상담 수·목록·학생 상세·상담 화면·모듈별 인원 그래프는 같은 최신 학생 집합을 사용한다. 모듈 화면은 공식 교육과정 카탈로그와 현재 합성 배정·이수 집계를 사용한다. 공통 가상 상담 메시지는 제거했다.

## 데이터 계약과 엑셀·CSV

첫 행의33개 영문 헤더는 `Students` 탭과 동일하게 유지한다. 예제 CSV는 docs/student-data-template.csv이다. `.xlsx`·CSV 자료를 구글시트로 가져올 때도 같은 탭·헤더와 자료형을 유지한다. 앱 안에서 임의 Excel 파일을 직접 올리는 기능은 현재 범위에 포함하지 않는다.

주요 규칙:

- `id`: 중복 없는 SYN-숫자7자리. `name`은 가상학생으로 시작, `synthetic=TRUE` 유지. 실제 학생 개인정보는 이 공개 합성 데모 시트에 입력하지 않는다.
- `active`: 앱 표시 여부. 최소1명, 최대1,000명. 시트 파서 입력 한도25,000행·16MB. 이는 보호 한도이며 최대 부하 검증 결과가 아니다.
- 학년1~4, GPA0~4.5, 점수/출석0~100. 점수·사회성 필드는 임의 UI 입력이며 타당화된 척도가 아니다.
- `moduleCreditsEarned <= moduleCreditsRequired`, `creditsEarned <= totalCredits`, 모듈 취득학점은 전체 취득학점 이내. 이수율은 앱 연결부에서 계산한다.
- 상태 Good/Warning/Request/Waiting. 공식 카탈로그의234개 모듈과 `selectedModules`의 ` | ` 구분 목록은 일치해야 한다.
- 상담일은 YYYY-MM-DD 또는 YYYY.MM.DD, 실제 존재하는 날짜만 허용한다. 진로·성찰·변경 사유·상담일은 공란 가능하다.
- 모든 행의 합성 식별자·synthetic·중복을 확인하고, 활성 행의 수치·필수값을 검증한다. 오류가 있으면 부분 반영하지 않는다. 오류 메시지의 행 번호는 CSV 데이터 행 기준이며 중간의 완전히 빈 행을 삭제하지 않는 것이 좋다.
- 셀 텍스트는 명령으로 실행하지 않는다. 시트의 열람 권한 변경과 실제 정보 입력 방지는 소유자 관리가 필요하다. 합성 플래그 검사는 개인정보 차단을 완전히 보장하는 기능이 아니다.

## 구현과 교체 지점

브라우저 `StudentDataProvider` → GET `/api/students` → 고정 설정의 Google CSV 읽기 → 필드·제약 검증 → Student 배열 및 원본 SHA-256 → React 공통 상태 → 각 화면.

- src/data/sheet-config.json: 특정 합성 시트 ID·탭ID·편집 URL. 사용자 지정 외부 URL을 API 인자로 받지 않는다.
- server/student-source.ts: CSV 파싱, 크기·행 한도, 합성·데이터 제약, 이수율 변환, snapshot revision.
- api/students.ts: 읽기 전용 Vercel Node Function. API·CDN 캐시를 사용하지 않고 실패를 명시한다. 비밀 인증정보를 클라이언트에 넣지 않는다.
- src/StudentData.tsx: 최초·주기·수동 요청, 단일 진행 요청, 취소·늦은 응답 처리, 마지막 정상 상태 보존, 집계와 네트워크 재계산.
- 선택 중인 학생은 ID로 최신 배열에서 찾는다. 변경된 학생 상세도 갱신하고 삭제/비활성화되면 열린 상세를 닫는다.
- 이번 공개 합성 시트는 링크 열람이 필요하며 편집권한은 소유자에게 둔다. 실제 학사 자료는 학교 API 또는 서버 인증이 있는 비공개 데이터 소스로 교체한다. 공개 앱에 실자료를 노출하지 않도록 사용자 인증·역할별 조회 범위도 함께 구현해야 한다.
- 학교 API는 `readSheet` 대신 인증된 어댑터로 구현하고 동일 Student 계약에 매핑한다. 이 문서가 실제 학교 API 연계나 실제 데이터 보안 검증을 완료한 증거는 아니다.

## 개발·검증

`npm run dev` 또는 `npm run preview`에서 배포와 같은 API 핸들러를 사용한다. `npm test`는 CSV 경계·형식, 잘못된 입력, 중복·합성 제한, 활성 인원 제한, 접근 실패, HTTP 읽기 전용·캐시 정책을 검증한다. `npm run check:sheet`로 실제 시트 읽기를 점검한다. 브라우저 테스트의 모의 응답 검사와 실제 시트 변경 검증은 연구 기록에서 구분한다.

## 동명대학교 교육과정 원자료 (2026-10-25)

공식 출처: https://www.tu.ac.kr/web/module-guidebook.html

4개 단과대학·24학과·234모듈·907개 교과목 로드맵 항목을 연결했다. 907은 고유 교과목 수가 아니며 선택 묶음은 한 요구 항목으로 유지한다. `src/data/tu-curriculum.json`은 이 연결의 버전 고정 카탈로그이다. Sheet의 Colleges/Departments/Modules/ModuleCourses는 그 내용을 확인하는 탭이며 카탈로그 자체를 수정하려면 소스·시트를 함께 갱신하고 재배포해야 한다.

Students는 합성1,000명(각 단과대학250명), StudentCourses는 이수 항목3,789행이다. 학생당 기본 모듈1개로 모든234모듈을 포함한다. 학년·프로필·점수·상태는 합성이고, 교과목·학점·권장 학년/학기는 공식 자료다. TU2026 학과ID와 Mxxx-Rxx는 연구 연결키이며 학교 공식 코드가 아니다.

StudentCourses H: completed/failed/in-progress/planned, I: completed는0초과~4.5, failed는0, 나머지는 빈칸. J:L과 Students H/J/K/L/AG는 계산값이다. 학점=completed 과목 학점 합, GPA=이수·F 포함 학점가중 평점(미채점 제외)이며 4.5체계는 시뮬레이션 가정이다. 학교 전체 성적표·졸업판정이 아니다. 미래 학년 과목의 완료, 중복·누락·출처학점/외래키 불일치는 거부한다.

`server/tu-matching.ts`는 두 CSV를 읽고 카탈로그와 교과목 원자료로 요약을 재계산한다. 시트 수식 캐시가 늦어도 원자료 계산을 우선한다. 내장 fallback도 같은 교육과정에 연결한1,000명이다. 기존28열 CSV 예제는 이전 버전 계약 참고이며 현재 원자료 입력 양식은 Sheet의 Students/StudentCourses 헤더를 따른다.
