# 합성 학생 데이터 — 학교 규모 1,000명

2026-10-25 사용자 요청에 따라 전체 학생 수를 1,000명으로 축소했다. 연간 입학정원으로부터 4개 학년의 총원을 추정한 수가 아니라, 이번 데모 전체 학생 수에 대한 설정이다. 실제 참여자는 0명이다.

- 구글시트 Students의 기존 첫 1,000개 식별자와 편집값을 보존하고 이후 행을 제거했다. 현재 1,000명 전원을 active로 표시한다.
- src/data/synthetic-students.json도 현재 시트의 1,000명 snapshot으로 바꿨다. 이 파일은 최초/연결 실패 시에만 쓰는 내장 데모이며 정상 연결 시 구글시트가 원본이다.
- docs/synthetic-data-manifest.json에 학교 규모·학년별 수·시트 revision·fallback SHA-256을 기록했다.
- 초기 20,000건 생성·256건 데모 및 검증 기록은 이전 버전의 이력이다. 현재 규모나 현재 화면 검증 결과로 인용하지 않는다.
- 구글시트 수정 후 지금 동기화 또는 활성 화면60초 주기로 갱신한다. [연결·입력 규격](GOOGLE_SHEET_SYNC.md)을 따른다.
- 연구 저장소 scripts/generate-synthetic-students.cjs의 기본 생성 수와 상한도 1,000건이다. 생성 결과를 편집 중인 시트에 자동으로 덮어쓰지 않는다.
- 이름·SYN 식별자·example.invalid 연락처·분기와 점수는 합성이다. 점수·관계·정서는 검증된 관찰 자료가 아니며 실제 요구·효과·AI 정확도·실증 표본 수로 해석하지 않는다.
